# Orialis Web

基于现有 Orialis HTTP API 的独立浏览器客户端。官网演示仍在 `website/`；本目录是真实账户数据客户端。

## 本地运行

需要 Node.js 20.19+ 或 22.12+，以及运行中的 Orialis 服务端。

```sh
cd web
npm ci
npm run dev
```

打开 <http://127.0.0.1:4177>。默认 `/api` 代理到本机 `http://127.0.0.1:18443`；可用 `ORIALIS_API_URL` 指定已有服务地址，例如：

```sh
ORIALIS_API_URL=https://your-orialis-server.example npm run dev
```

登录现有账号或创建账号。会话令牌仅在当前标签页的 sessionStorage 中保存，刷新保留，关闭标签页结束；退出登录会撤销服务端 Session。

## 功能

- 今天：当日日程、已到期未完成任务与快捷完成。
- 任务：创建、编辑、完成、删除、项目关联、截止日期和时间、重要/紧急三态分类；搜索标题/备注/项目名，组合筛选完成状态、所属项目和截止范围，按截止日期/优先级/名称排序。编辑、完成、删除或刷新后保留当前筛选。
- 项目：创建、编辑、状态、目标、开始/截止日期、删除；显示服务端汇总的任务与里程碑进度、下一步行动；查看关联任务，在项目筛选下新建任务会默认关联该项目。
- 聊天：读取会话、新建会话、发送文本、每 5 秒自动刷新消息和手动刷新。阅读历史时保持滚动位置，隐藏页面暂停、离开聊天停止刷新；请求失败保留消息并自动重试。切换会话保留各自草稿与发送错误，重复提交锁定，失败后相同内容重试沿用原消息 ID。草稿仅存在当前聊天页内存中，离页或刷新浏览器后清空；真实 Agent 回复依赖现有设备在线。
- 日程：周/月/列表视图、日期导航、搜索、创建/编辑/复制/删除、地点、备注、重要标记、跨天、全天、提醒设置。
- 复杂日程：日/周/月重复、间隔、选定星期、生成数量与截止日期，保存前预览、已有日程及本批次重叠提示。

## 日程语义

重复安排生成最多 100 条独立日程，使用现有 `/schedules` 接口，无需修改服务器或移动端。没有“整组修改”“仅此后所有日程”或无限重复系列。每月遇不存在的日期跳过；每次的本地墙钟时间保持一致，遇夏令时不存在的时间跳过。

编辑器按浏览器时区显示和输入，写入 UTC RFC3339。全天输入的结束日包含在内，保存为次日零点的排他结束。跨时区旅行时，全天仍遵循当前服务端的绝对时间语义，不另建浮动时区字段。

读取完整分页后在浏览器按实际时间过滤，避免漏掉从上一周/月开始的跨天事件。更新携带 `baseVersion`，409 保留编辑器草稿并提示刷新后重试，不静默覆盖其他设备更新。批量保存逐条提交，并保留固定 ID；中途失败会报告已确认数量，重试前查询对账，继续剩余条目。不是整体事务；关闭失败编辑器会保留已保存的条目。

提醒参数同步给已有客户端；Web 不发送后台系统通知。页面刷新或“刷新”读取服务端最新数据。没有浏览器 WebSocket 握手扩展、离线写入队列、附件上传或新闻入口。

## 验证与交付

```sh
npm test
npm run build
```

`dist/` 是构建产物。生产环境需把静态文件与 `/api` 放在同一来源，由反向代理转发 API 到已有 Orialis 服务端（示例见 `nginx.example.conf`）。Vite 的开发代理不会打包进静态文件。必须保留 HTTPS，不能把 Session 写入 URL。

实现与本地验收记录见 [初版与日历](../docs/implementation/web-calendar-20261013.md) 和 [任务、项目与聊天完善](../docs/implementation/web-improvements-20261023.md)。未部署生产站点。
