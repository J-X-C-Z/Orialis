# Bilibili storyboard reference

`memory_video.py` adapts storyboard index normalization and frame selection/cropping
from [c1overzz/dsh-bili-scroll](https://github.com/c1overzz/dsh-bili-scroll), commit
`5be5f6d57c47c7e79ad9bc4ce39457b68a160dfa`, `vendor/bilibili-mcp/mcp_server.py`.
The upstream Bilibili MCP source is AGI_Ananas/bilibili-mcp. The HTTP client,
validation, background worker and integration are implemented for Orialis.
