# 验证记录

本轮使用 Flutter 3.47.4 / Dart 3.13.3。不能以生成平台目录代替运行或编译验收。

- 组件库：50 项测试通过；`flutter analyze lib test` 无问题。包含开关、分段控件及数值滑块的点按、长按拖动与松手吸附回归。
- Orialis 接入：150 项测试通过，1 项在线集成测试跳过；静态检查无问题。项目摘要已展示 active/completed/archived 状态。周视图时间占用网格曾试做并真机查看，标题在窄列中被截断、质感不达标，已回退到七个纵向日卡布局；周范围标题一并回退。
- Android：Orialis arm64 release 已成功构建、覆盖安装并启动；检查了事件页真机截图。截图中的刷新率数字不能作为帧耗时或持续帧率结论。周视图新网格尚未重新真机截图验收。
- 展示应用：独立运行，不依赖 Orialis；示例冒烟测试与静态检查通过；Web release 构建通过，并在本地浏览器检查了组件展示。
- iOS / macOS：只有示例平台工程；当前电脑仅配置 CommandLineTools，未完成原生编译或真机验收。
- Windows / Linux：未编译、未验收，不声明已验证支持。

组件测试覆盖连续切换、拖动吸附、减少动态效果、主题与语言、完成反馈和持久化/触觉适配；新增测试验证凹槽保持位置而玻璃滑块移动。
