# 应用商店候选版真机验收

每一项需在准备提交的正式签名 APK 上完成。记录手机型号、Android/HyperOS 版本、网络、结果和问题录像；不能用 debug APK 的结果代替。

## 用户痛点回归

- [ ] 冷启动：首次安装先出现隐私弹窗，弹窗前不发起方寸网页请求；拒绝后退出。
- [ ] 再次冷启动：立即出现原生加载界面，不出现长时间白屏；网页首帧出现后加载界面消失。
- [ ] 未登录：任何情况下都不能先闪现任务、课表、姓名或管理后台，再切到登录页。
- [ ] 弱网/断网：有明确反馈，恢复网络后可继续；连续点击不会生成重复任务或重复同步。
- [ ] 快速操作：连续切换板块、翻周、保存、同步、返回 5 分钟，不崩溃、不冻结、不出现不可恢复遮罩。
- [ ] 日历范围：当前学期结束后仍可逐周、逐月继续浏览，普通日期正常显示。
- [ ] 手机课表：顶部信息仍完整，但固定区域不过度占屏；首屏可见足够多课表内容。
- [ ] 命名：入口使用“同步”或“课表同步与导入”，不再把备份恢复、系统日历和文件导入都统称为“导入课表”。

## 上架功能回归

- [ ] 注册、登录、退出、修改密码、注销账号全流程成功。
- [ ] 注销前必须验证当前密码；注销后旧会话失效，重新登录失败。
- [ ] 隐私政策可从首次弹窗、登录页和云端设置打开；主体、联系方式、APP/ICP 备案号均为真实公开值。
- [ ] 通知、闹钟、日历权限均由具体功能触发，拒绝后其他功能仍可用。
- [ ] 竖屏、横屏、刘海/挖孔、手势导航和系统字体放大均可操作。
- [ ] 后台恢复、系统回收后恢复和设备重启后的提醒行为符合说明。
- [ ] 从旧版升级保留账号与数据；全新安装不携带测试数据。
- [ ] 4 张商店截图与当前正式包界面一致，且不含真实个人数据。
