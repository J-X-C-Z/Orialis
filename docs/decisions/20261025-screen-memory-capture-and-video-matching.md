# 屏幕记忆：按需辅助截屏、后台执行与视频匹配

状态：已实施。来源：用户2026-10-25要求取消每次快捷截屏弹窗、默认不打开Orialis，并允许AI依据标题与UP主搜索原视频后理解。

此前`integrations/hermes/orialis/README.md`规定“不按标题搜索或猜测隐藏链接”。当前用户明确要求标题与UP主搜索，按指令优先级取代其中“不按标题搜索”的限制；仍禁止猜测隐藏链接和未经核验的视频编号。

Android 11以上在用户手动启用“Orialis 辅助截屏”后，快捷键调用官方AccessibilityService.takeScreenshot，仅此时读取截图和可见应用文字。没有授权时保留MediaProjection的系统确认，不尝试跳过系统强制同意。保存成功后不启动MainActivity，停留在原应用；记忆页仅增加明确的截屏设置入口。

保存钩子通过系统JobScheduler启动短期headless Flutter任务，复用AppConfig的安全登录存储、账号隔离收件箱与既有记忆API。完成、超时或系统停止后销毁引擎，不新建聊天、不复制明文令牌。稳定任务ID支持恢复；成功/失败提交在原生同步锁内比较analysisRequestId，防止后台旧任务覆盖前台的新重试。

后台来源优先级为原始URL、完整可见BV号、标题与UP主搜索。最后一种仅在AI确认B站视频且两项文字来自同一视频时使用。搜索限制一页20条，标题按Unicode/标点规范化、作者名同时匹配，唯一候选还须通过实际视频详情核验。明显截断标题只允许至少12个规范字符的前缀，短标题与模糊候选不自动采用。搜索得到的canonical URL来自平台核验的BV号，不声称从截图直接读取。

不改Rust服务、数据库或记忆线协议；新增OCR字段只在模型与读取器内部流转。其他平台继续保留原链接，视频理解仍只使用真实字幕或抽样画面。

验证和发布见`docs/implementation/screen-memory-capture-search-20261025.md`。手机源码通过测试/编译，尚未安装；具体ROM的控制中心收起、授权与冷进程执行仍需统一手机发布后验收。
