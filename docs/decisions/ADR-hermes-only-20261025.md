# ADR：Orialis 统一由 Hermes 执行 Agent 工作

日期：2026-10-25。状态：接受，来源为用户当轮明确指令。

## 背景

Orialis 曾同时注册 Hermes、DSH 及旧 Codex 网关；设备和会话目标可能指向不同执行器，DSH 接入还具有独立的文本/工具能力限制。

## 决定

Orialis 现用 Agent 执行入口统一为 Hermes。Mac、Windows、Hakari、Azure 各自保留本机 Hermes，服务器继续负责账号、消息持久化和精确设备路由。模型和执行器分离：使用 Hermes 不要求使用同一个模型；现有可用模型接入保持，各 profile 必须有完整有效的模型配置。

将有效 DSH 及旧 Codex 会话显式迁移到对应主机的 Hermes；没有任何在线自动回退到 DSH 的入口。历史代码和离线注册记录可保留作审计，不能据此声称 DSH 仍承担执行。API、数据库及普通采集服务继续各自职责。

## 验收与后续

以四个精确设备的真实消息回复及线上绑定读回验收。客户端只展示/接受配置的 Hermes 设备；客户端源码与已安装手机包的交付状态必须分开记录。切换保留逐会话绑定和 profile 配置备份，不允许覆盖升级后产生的新数据。

## 影响

DSH 专属文本限制不再适用于当前选中的 Hermes 入口。用户此前提出的“先简短回应、再输出完整回复”属于后续消息生命周期改动，本次统一执行器不等同于该功能已经实现。
