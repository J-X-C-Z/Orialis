# Orialis 1.2.0

Orialis 1.2.0 makes the neumorphic and glass interface the main mobile experience and includes the backend capabilities required by it.

## Mobile

- Adds the recessed neumorphic and refractive glass title treatment across the phone interface.
- Adds the layered bottom navigation: a glass frame, a neumorphic bed, and a moving refractive lens with etched labels.
- Expands Intelligent UI to 20 native block types and six chart kinds, including progress, heatmap, accordion, tables, form controls, attachments, and message search.
- Makes phone page switching immediate by removing the full-surface branch animation. Inactive pages remain offstage with their state, drafts, and scroll positions while tickers, pointer handling, focus, semantics, and painting are disabled.
- Reuses rendered navigation labels and validated rich response documents, and moves heavy screenshot image work to the existing background workers.

## Backend

- Production API reports 20 response UI block types and six chart kinds.
- Hermes emits useful progress summaries only when there is new public evidence, uses stable final reply identities, and suppresses empty-stream placeholders.

## Platform scope

This release installs the updated Android application. The Mac and Windows desktop applications are not replaced by this release.

## Verification

The Android package is built and installed with data-preserving `adb install -r`. Release verification covers the APK manifest, SHA-256, signing certificate, installed package identity, public API health, and API capability readback. Extended tests and performance benchmarks are not claimed for this release.
