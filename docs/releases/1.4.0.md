# Orialis 1.4.0（55）

- 日历将日／周／月与日期切换合成一行；事件将四象限／项目与筛选合成一行。保留点击区域，大字号与窄屏可横向滑动。
- 汇入近期已完成的统一账号登录、记忆云同步、原图本地保留、日历日周月视图与交互动效更新。
- 新增 iOS 工程及个人重签用 IPA，复用任务、日程、项目、聊天、资讯与记忆云同步。

## 下载

- `Orialis-1.4.0-arm64.apk`：Android 7.0+ ARM64，沿用原证书，可覆盖更新保留数据；应用内 GitHub 更新器可识别。
- `Orialis-1.4.0-ios-self-sign.ipa`：iOS 15+ ARM64。当前没有可安装的 Apple 签名或描述文件，必须使用自己的 Apple ID 在个人签名工具中重新签名；见 [iOS 自签说明](../../mobile/IOS.md)。
- `Orialis-1.4.0-source.tar.gz`：对应发布源码。使用 `SHA256SUMS` 核对附件。

iOS 的跨应用辅助截屏、外部分享接收、原生日历同步、系统通知与长期后台分析、小米手环原生连接尚未移植。记忆同步随应用运行和回到前台执行，详见 iOS 说明。
