# Orialis 1.3.0

Android arm64 · versionCode 37 · Android 7.0 及以上。

## 更新内容

- Intelligent UI 从 20 类扩展至 26 类，新增提示、步骤、方案对照、详情、代码与复制、日程提案；统一轻拟态光影、图表和内嵌玻璃控件。
- 日程支持先预览并编辑标题、时间、地点和备注，再明确确认添加。重复点击或重新打开同一提案不会重复创建，并分别展示本机保存、待同步与同步结果。
- 改善聊天悬浮输入和操作控件，适配键盘、多行输入、窄屏与大字号。
- 高性能模式使用静态磨砂和缓存光影，导航与控件减少实时背景采样，并按屏幕刷新率调整模糊预算。

## 安装

下载 `Orialis-1.3.0-arm64.apk`，或在应用“我的 → 软件更新”中检查更新。安装包沿用此前发布版签名；Android 安装器会要求确认更新。SHA-256 见附件 `SHA256SUMS`。

## 验证范围

真机帧率和真实日历跨设备同步仍待验收。Windows Hermes 提示升级仍待空闲窗口。
