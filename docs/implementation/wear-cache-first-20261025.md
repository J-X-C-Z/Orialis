# 手环缓存优先首屏 · 2026-10-25

来源：用户要求进入手环端立即显示缓存，不先显示“等待手机同步”。工作树：repo-latest，基础提交 719f51c。实现范围：band/vela/**；保留现有其他工作树修改。本次采用 Coder 的 assigned-task-paths 边界；独立只读复核检查了启动顺序与手机同步竞态。

## 行为与实现

- 已在内存中的快照作为页面初始视图，并在页面初始化/显示时应用共享 store。
- 冷启动同时请求快照和会话 guard，等两者完成且 guard 校验通过才展示缓存。此前两次读取串行执行，读取前页面误报无数据。
- 新增 cacheLoading，仅在本地读取尚未完成且没有可用快照时显示本地读取提示；不展示空数据/手机连接提示。内存已有数据时不隐藏内容。
- 手机诊断与缓存读取并行，手机离线或诊断不回调不会阻塞缓存显示。
- 缓存恢复期间收到的完整快照进入现有最多四项队列；恢复完成后按会话与 revision 校验并持久化，不要求手机重发。清理/撤销仍可执行；ACK 仍只在写入精确回读通过后发送。
- generation 和读取批次编号隔离迟到回调；清理、会话变化和销毁后不会被旧读取恢复数据。缓存仍保留原有 stale/只读标识。
