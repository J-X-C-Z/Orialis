承接新UI提升main及底部导航要求，版本1.1.1+21。只安装Android，Mac/Windows既有13不替换。本次不改数据库/迁移/API、CPU绑核或系统调度策略。

## 已实现

- 导航行及图标文字作为AnimatedBuilder.child复用，拖动每帧仅更新共同的位置、蚀刻形变和透镜；外玻璃框、轻拟态内层与真实折射保持20方案。
- MarkdownBlock的Intelligent UI文档/安全校验/摘要指纹按弱引用键复用，跟随既有48段缓存及消息生命周期回收，不扩大为第二个无界正文缓存。回调和消息actionScope仍由各组件独立传入，跨账户相同内容不共用操作身份。
- 空附件直接返回空列表；同一消息构建只格式化一次时间。
- Well/嵌入玻璃渐变复用原两组64项LRU缓存；不再测量未使用或轻拟态不显示的标题肩部。普通高性能点击不启动多余spring，导航跟手弹簧仍在。
- 普通模式保留原磨砂采样；高性能模式保留已绘制的凹陷、磨砂底色和玻璃盖层，省去每个Well的BackdropFilter。导航单个局部折射ImageFiltered不受影响。高对比/减少透明度不创建禁用滤镜。
- Android辅助截屏的全屏Bitmap复制从UI回调移到已有单线程worker；释放HardwareBuffer/bitmap并处理关闭期间的提交拒绝。截图、系统截屏和分享图像线程使用Android后台优先级，减少单核心争用，多核分配交给系统。未增加线程池或并行调度框架。
- 已确认现有Drift主数据库默认后台连接，Dio默认对达到50KiB的JSON响应采用isolate转换；继续复用，不叠加额外工作线程。
