# 云端更新自动同步（2026-10-31）

已完成源码与自动化验证，尚未发布或安装新客户端。

## 行为

- 手机和桌面共用 SyncCoordinator：已有云端实时变更通知立即触发增量同步；新增前台每30秒补同步，漏通知或网络失败后无需手动刷新。
- 返回前台沿用现有立即重连与同步；退出前台暂停定时检查。应用被系统挂起或关闭时不会保持轮询。
- 手机和桌面都监听本地任务/日程/项目/里程碑的outbox变更，250ms合并后同步；沿用原有版本冲突和本地编辑保护。
- 定时检查不叠加正在运行的同步；账号切换销毁旧协调器、取消定时器并等待旧请求结束。
- 网页日程、今天、任务和项目每30秒自动刷新，恢复联网/切回页面立即刷新；编辑表单时延迟，保留任务筛选；聊天复用原来的局部轮询。
- 网页账号切换会拒绝旧账号HTTP响应；首次加载失败也保留自动重试入口。
- 手环沿用已有手机数据库变化→快照→ACK同步链路；本次未修改手环协议。记忆云存储由并行任务负责，本次未重复实现。
