## 已实现

- 任务：标题/备注/项目名搜索；完成状态、项目（含未关联）、截止范围组合筛选；截止日期、重要/紧急优先和名称排序；逾期标记、显示数量、清除筛选。逾期按浏览器本地日期与可选截止时间判断，已完成任务不计逾期。新建、编辑、完成、删除和刷新后保留当前筛选。
- 项目：复用 `/projects/{id}/summary` 显示任务与里程碑的综合进度、完成数量及下一步任务；可直接进入该项目的任务列表，并为新建任务预填项目。汇总失败保留卡片并提示重试；连续刷新时忽略旧列表的迟到响应。
- 聊天：每 5 秒查看当前会话最新消息；保持历史阅读位置；读取失败保留当前消息并自动重试；页面隐藏暂停、离开聊天清理轮询。各会话独立保留草稿、发送状态与错误；发送锁防重复提交，相同内容失败重试复用消息 ID；发送中继续编辑的文本会保留。
- 窄屏：任务操作按钮移至独立一行，项目卡片文字可换行，390px 任务/项目/聊天均无页面横向溢出。

聊天草稿仅当前聊天页内存保留，离页/刷新后清空。自动更新采用已有 HTTP API，不新增 WebSocket 认证协议或后台通知。
