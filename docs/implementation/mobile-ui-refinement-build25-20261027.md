# 手机界面细化 · build25

## 实现

- Today / Events 局部字体比例改为 0.92，保留系统字体缩放、主题和触控区域。
- 导航外框增加局部磨砂背景；透镜加厚，与外框上下边缘齐平。文字图标不经过整块图像滤镜。

- 周末、选中日期、日程圆点和截止菱形增加语义配色；日程卡为绿色，截止卡为琥珀色。
- 手机主导航恢复220ms轻水平进场；导航栏固定，隐藏分支保留状态，减少动态效果时退为轻淡入。
