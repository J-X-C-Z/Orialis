# 手动跟踪正在进行的日程

用户已明确选择扩展原有日程：手动开启跟踪，显示日程名称及剩余时间，结束或取消撤下。此项取代前次“现有通知无合适候选”的范围判断，但不改变聊天、提前提醒或日程变更通知的用途。

## 行为边界

- Android 日程详情提供跟踪操作，只允许有效的 `start <= now < end` 日程开始跟踪；未来和已结束日程不自动开启。
- 一次跟踪一个日程。跟踪与提前提醒时间独立，没有设置提醒的日程也能跟踪。
- 使用标准通知标题和系统倒计时。Android 16+ 请求 Google Live Updates；旧系统保留普通持续通知。紧凑状态栏/岛的可用宽度与显示样式由系统决定，展开通知显示完整标题和剩余时间。不会用自定义悬浮窗模拟岛。
- 手动停止或划掉后不自动恢复。日程删除、结束、改期至非进行中，或账号/系统集成状态失效时撤下。
- 本地日程变化通过现有数据库投影刷新。其他设备的取消/编辑需要同步到本机才能反映；不新增后台推送渠道，不承诺离线接收远端取消。
- 不把聊天中间消息、普通提醒、单次截屏和后台分析改成 Live Updates。

## 验收场景

在支持 Live Updates 的 Android 16+ 设备上，允许 Orialis 通知及系统的实时更新展示，打开一个正在进行的日程详情并开始跟踪。检查名称、剩余时间、点击返回详情及停止操作。另测无提前提醒的日程、到时自动撤下、删除/改期撤下、切换账号撤下、划掉后刷新不重发、跟踪新日程替换旧日程。关闭 Live Updates 展示但保留通知权限时应仍有普通通知；旧系统不调用新 API。
