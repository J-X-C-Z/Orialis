# 手机聊天设备入口调整 · 2026-10-25

本次用户确认范围：Orialis 手机端聊天页顶栏设备入口。验收目标是合并重复入口、消除点击后等待接口才出现面板的停顿、增加设备卡片间距、用聊天状态环样式显示设备在线状态，并以长按卡片修改设备名称。

## 实现

- 聊天列表顶栏原有“与设备对话”和“新建会话”都进入 `_chooseChatDevice`，现在保留单一设备入口。会话内更多菜单和空列表的新建入口继续使用相同流程。
- `ChatDevicePicker` 在面板内部加载设备列表，面板先展示标题、操作提示与加载反馈。取消了进入面板前的网络等待；未改变服务器接口耗时，也未宣称网络请求本身变快。
- 设备卡片间距为 16，标题与列表之间为 24。右侧复用 `AgentStatusRing` 显示本次设备查询的在线/离线状态，点击提示状态；不把设备在线推断为助手正在回复。
- 长按设备卡片打开原名称编辑对话框，保留空名校验、取消与保存失败提示。保存后直接更新卡片及后续创建会话使用的显示名称，不重新请求设备注册表。设备 ID 和路由不变，离线设备依然不能开始会话。
- 同步设备服务测试中陈旧的三台设备断言，匹配源码已有 Mac、Windows、Hakari DSH、Azure 四个配置槽位。服务实现未修改。
