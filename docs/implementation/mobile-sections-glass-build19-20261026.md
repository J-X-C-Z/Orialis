# Orialis 手机其他页面凹陷玻璃标题适配 — build19

用户要求“其他界面也适配”。继续只更新手机端，沿用18的凹陷磨砂底座、清晰文字与玻璃盖层；Mac/Windows保留13。

## 当前覆盖

- 手机应用根部启用标题材质作用域：事件象限与折叠分区、项目卡片与里程碑、资讯折叠栏目、穿戴连接设置、个人资料和系统设置的共用分区标题统一继承。
- 普通分区将标题放进同一张内容卡片中，形成左上凹陷玻璃标题区；独立折叠标题保留原标题点击、状态记忆与折叠动画。
- 日历“日程／当天截止”使用同一标题材料。
- 聊天Intelligent UI总标题与20类富卡片分区标题在手机作用域中接入；正文、表格/图表、表单等实际内容保持各自布局，复制摘要按钮保留独立右侧操作。
- 记忆详情六类标题（摘要、视频理解、笔记、链接、截图、原始内容）及设备卡片名称使用共享标题；未把列表正文、任务名称或普通消息全部套成玻璃按钮。

共享标题glassTitle可选值未指定时继承作用域，显式false可保留原标题。作用域默认关闭，OrialisApp仅在Android/iOS且非desktopMode时开启；桌面和作用域外保留原布局。高对比不画玻璃，减少透明度时保持不透明回退。原玻璃画笔、导航及desktop_shell未改。
