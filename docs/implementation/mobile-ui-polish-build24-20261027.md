# 手机 UI 材质与性能优化：1.2.1+24

2026-10-27，基于主线 c08d17f。用户本轮要求颜色点缀、轻拟态层次、Intelligent UI 原生控件、性能及动效优化、嵌入玻璃的紧凑导航、圆形加号入口、侧边和底部布局修正。

- 玻璃标题使用对应卡片强调色；Intelligent UI 类型标签增加轻色底，线性进度使用真正的凹槽材质与受约束的渐变填充。保留 0/部分/100% 的数值和读屏描述，减少动态效果及高性能模式下立即显示目标值。

- 我的、系统设置、设备、屏幕记忆页面把左右 20px 内容留白移进滚动视口，消除阴影被窄视口裁成垂直侧条的现象。系统状态栏/手势区域随主题，关闭系统额外对比度遮罩。
