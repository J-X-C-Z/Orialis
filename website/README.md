# Orialis 官网原型

这是一个用于比较三种品牌官网编排的本地原型，设计源自 Halo 02，并围绕“强大的 AI 自然围绕日常”展开：

- **A · 循光旅程**：主推荐方案。沿着光带，从深空进入日程、资讯，最后回到温暖平静的日常。
- **B · 星系漫游**：以星系地图开场，可直接选择日程、资讯等入口。
- **C · 日常来信**：以文档流方式阅读内容，产品场景沿页面自然展开。

## 本地预览

在本目录执行：

```sh
npm install
npm run dev
```

然后打开 A 方案：<http://127.0.0.1:4176/prototype/?variant=A>。`variant` 可设为 `A`、`B` 或 `C`。开发预览提供方案切换控件，也可用键盘左右方向键切换；页面的“减少动态”开关可关闭行程动效。

构建和本地预览构建结果：

```sh
npm run build
npm run preview
```

## 日程与资讯演示

日程和资讯交互只在当前页面内运行。日程使用预设示例，可查看并调整时间；资讯展示明确标注的示例重点与参考入口。演示不会写入真实账户、日历或服务端。

本原型尚未公开发布。

## 主要文件

- `index.html`：页面入口和基础元信息。
- `src/main.ts`：页面结构、章节导航、方案切换和动效编排。
- `src/halo.js`：Halo WebGL2 渲染及降级处理。
- `src/style.css`：官网布局、品牌视觉和响应式样式。
- `src/demos.ts`、`src/demos.css`：本地日程与资讯交互演示。
- `public/halo.svg`：站点图标。
- `MOTION_SPEC.md`：设计来源、三种方案及动效方向说明。
