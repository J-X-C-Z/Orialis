Runtime logs report `versionName 0.2.1-ui`, `versionCode 3`, and creation/show of `pages/home`. The AIoT IDE GUI interaction path was not established, and no source fix was attempted against the concurrently updated 0.3.0 tree. This task remains blocked pending group-lead review of the gesture result and a usable display/control session for the remaining matrix.

## Reproduction and findings

1. `npm run start` first exited because the non-TTY prompt could not choose an AVD. Running in a TTY exposed the 10Pro configuration issue: `image.sysdir.2` was absent. The toolkit's `VvdManager.resetImageDir('10Pro')` restored the image path without deleting the AVD or its data.
2. A subsequent watch build read the concurrently updated working source: its manifest was already `0.3.0-ui` / versionCode `4` (manifest SHA-256 `77526f9086efa316cc6bea29a9d353a3545f98bbfcf8f870bc2f70b78dbccc15`). That run generated `band/vela/dist/top.jxcz.orialis.debug.0.3.0-ui.rpk` (140,135 bytes; SHA-256 `cf3793d0788c2bc9cae96a777be2118ea85547dd785f00cc5cc883dbbd7eec72`) and the emulator later went offline during watch reload. It is not used as 0.2.1 evidence. The leader's frozen 0.2.1 RPK above remains available and was used for the isolated runtime attempt.
3. A real center tap and horizontal swipes were sent through the emulator controller after the frozen RPK launched. The runtime log records the Home-to-Devices page creation following the tap. The subsequent right swipe at `y=240` produced no new Home page creation, and its post-swipe screenshot has the same SHA-256 as the Devices frame taken after the left swipe. This does not establish the desired horizontal return. Earlier files in `acceptance-0.2.1/` are not trustworthy by filename: for example, `03-commands-empty.png` depicts Devices, `14-settings-demo-on.png` depicts Home, and `11-back-from-tasks.png`, `15-settings-scrolled-demo.png`, and `18-horizontal-left-from-commands.png` are blank white frames. None are cited here as passing evidence.

The build updated `band/vela/dist/` to the concurrent 0.3.0 artifact. No source file was edited during this review. `services/transport.js`, `test/transport.test.js`, and `mobile/**` were not edited.
