# 手环 1.3.0 适配记录

2026-10-28。本次按手机正式版 1.3.0 适配，手环版本 1.3.0 / versionCode 15。源码基于 ui-neumorphic，保留并行聊天等其他改动，未提交或发布。

## 改动

- 统一首页、列表、日历、项目、设置的静态暗色卡片、边缘高光和凹槽层次，保留紧凑模式与减少动画。我的页外观入口进入本机设置，显示版本。
- 修复真实协议漂移：手机曾允许 384 KiB / 220 片，而手环只接收 16 KiB / 32 片。手机限制现对齐接收端；沿用 namespace/schema，不增大手环内存预算。
- 在容量内优先今天、逾期、未来、无日期、已完成任务，以及进行中、未来、已结束日程。覆盖数量和总量真实显示；新确认日程在服务端同步后进入快照，不将未确认提案或本地待同步数据冒充云端记录。
- 混合时区日程按真实时间排序；全天日程详情使用实际最后一天；同步时间按手机偏移显示，偏移未知时明确 UTC；最近截止保留手机手动顺序。未知云端同步状态明确显示中文“同步状态未知”。
