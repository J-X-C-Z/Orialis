## 页面与可操作预览

| 页面 | 手机现有语义 | 手环界面 |
|---|---|---|
| 今日 | 现在关注、最近截止、接下来与稍后日程 | 重点任务、最近三项截止、日程卡及详情 |
| 事件 | 待完成/无截止/已完成、四象限/未分类 | 切换筛选和象限；详情调整象限、上下排序、重置排序、撤销 |
| 任务 | 重要/紧急 nullable、截止日期/时间、备注/项目/提醒 | 选项编辑、逐日和逐时/逐分步进；重复规则仅保留、显示，在手机编辑 |
| 子任务 | 只有根任务能管理一级子项；parentTaskId与scheduleId互斥 | 子项添加/编辑/完成/删除；父完成级联子，父重开保留子状态；子全部完成派生父完成，子重开派生父重开 |
| 日历 | 日/周/月、前后日期、回今天、日程与任务截止分开 | 日周月切换、七列月格与项目计数、选日、当日列表、新建及详情 |
| 日程 | 开始/结束、全天、地点/描述/重要/提醒、附属任务 | 独立起止日、完整分钟步进、全天结束日采用翌日排他endAt、关联任务及删除确认 |
| 项目 | name/goal编辑、列表排序、状态只显示、里程碑/关联任务 | 名称/目标编辑、排序、状态及下一步只读、里程碑创建/编辑/完成/删除；排序仅同项目 |
| 我的 | 账户/服务器/同步/外观/性能/设备 | 非秘密账户/同步摘要，手机操作说明入口，设备状态、手环设置、连接诊断和快捷指令 |

五个入口为今日、事件、日历、项目、我的，事件内也可到项目。没有聊天路由、对话、消息或附件输入。黑底、深灰圆角卡、44px彩色圆圈和各域独立线条图标沿用方寸设计。

## 编辑约束和数据来源

默认空数据，缺`view.organizer`不把legacy agent `view.tasks`冒充用户任务。接收v1 organizer时显示各域included/total和部分数据说明；完整快照仍受既有16KiB UTF8协议限制。手机utcOffsetMinutes用于时间显示和日区间[start,end)交集，不按UTC字符串切片判定日历日期。

目前所有真实手机/缓存数据只读；编辑、完成、删除、排序均提示在手机处理。用户显式开启「查看互动演示」后，操作只修改本地内存，保存提示「本地演示」，不会发RPC、写手机或保存重放队列。关闭演示、重启、已接入的scope撤销/切换及清缓存会清除演示和详情。真实认证会话事件源仍未接通，不能把本地scope钩子当成实际账号隔离验收。

Vela小屏编辑用点击切换标题/备注/地点/目标预设及现有原文，日期与时间可逐日/逐分钟选任意有效值。自由中文输入明确在手机完成，不添加未确认支持的text input。手机通知本身仍只有提醒元数据，手环没有宣称通知送达能力。

项目删除对齐当前本地ProjectRepository：只移出项目列表，不新增任务解除关联或里程碑级联语义。项目状态/nextAction不提供setter，重复规则不提供编辑器。真实设备配对、确认/拒绝、撤销和账号凭据保留手机操作入口与说明。
